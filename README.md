# 🎰 Python Slot Machine

A simple command-line slot machine game built with Python.  
The player deposits money, chooses betting lines and bet amounts, spins the machine, and earns winnings based on matching symbols.

## ✨ Features

- 💰 Starting balance/deposit system
- 🎯 Choose 1–3 betting lines
- 💵 Choose bet amount per line
- 🎰 Random 3×3 slot machine
- 🏆 Automatic winning detection
- 💳 Balance tracking
- 🔄 Multiple rounds
- 🛑 Quit anytime
- ⚠️ Input validation
- 📊 Different symbol values and probabilities

## 🎮 How to Play

1. Start the program.
2. Enter your starting deposit.
3. Choose the number of lines to bet on.
4. Choose how much to bet on each line.
5. Spin the slot machine.
6. Matching symbols on a selected line result in winnings.
7. Continue playing or quit.

## 💻 Requirements

- Python 3.x

No external libraries are required.
